# Clinic Management System - C++

## Project Description

A console-based Clinic Management System developed in C++.

The system manages patients, doctors, the waiting room, and patient visit history.

It supports:
- Adding, viewing, searching, and deleting patients
- Managing doctors
- Priority-based waiting room
- Emergency and normal visits
- Patient visit history
- Sorting patients by name or age
- Searching patients by ID
- Calculating the total amount paid by a patient

## Object-Oriented Programming

The project demonstrates:
- Classes and objects
- Encapsulation
- Inheritance
- Abstract classes
- Polymorphism
- Virtual functions
- Operator overloading
- Destructors

## Data Structures

The project uses custom data structures:
- Priority Queue using a binary heap for the waiting room
- Linked List for patient visit history

## Algorithms

- Binary Search for searching patients by ID
- Selection Sort for sorting patients
- Recursion for calculating total visit fees
